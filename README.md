# Food

A modern and responsive website for a food delivery service. The website features a beautiful UI with interactive elements including:

- Modal windows for contact forms
- Tab system for different menu categories
- Image slider
- Form validation
- Responsive design for all devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Validator.js for form validation

## Features

- Responsive design
- Interactive UI elements
- Form validation
- Modal windows
- Image slider
- Tab system
- Clean and modern design

## Setup

1. Clone the repository
2. Open `index.html` in your browser
